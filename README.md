# English Steps

A small CEFR-graded English reading website. The site is a single static HTML file and can be hosted with GitHub Pages.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The page uses browser speech synthesis for reading aloud and an online translation service for words that are not already in the article glossary.
