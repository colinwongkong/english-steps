# English Steps

A small static website for CEFR-graded English reading practice.

## Files

- `index.html`: level and topic library with featured illustrations.
- `article.html`: standalone article reader opened in a new tab.
- `articles.js`: article text, Chinese translations, and glossaries.
- `site.css`: shared responsive styles.

## Features

- Six CEFR levels, from A1 to C2.
- Browser speech with pause/resume and repeat controls.
- Clickable words with article glossaries and online lookup for other words.
- Locally stored SVG illustrations on the homepage.

The page uses browser speech synthesis and an online translation service for words not already in an article glossary.
